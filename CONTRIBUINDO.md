# Como contribuir

Obrigado por querer contribuir com este projeto!

1. Faça um fork do repositório.
2. Crie uma branch para a sua alteração: `git checkout -b minha-alteracao`.
3. Faça suas mudanças e escreva mensagens de commit claras.
4. Envie a branch para o seu fork: `git push origin minha-alteracao`.
5. Abra um Pull Request descrevendo o que mudou e por quê.

Dúvidas ou sugestões? Abra uma issue.
